# 「できた！」プロジェクト

スクールの生徒さまの目標と、その先に生まれた「できた！」を紹介する特設サイトのモックです。


## コースタグと個別URL

- `src/data.js` の各ストーリーに `courses: ['guitar', 'vocal']` のように複数コースを設定できます。カードと詳細にタグを表示し、各コースの絞り込みに対応します。旧形式の `course` も利用できます。
- 空配列・省略・無効なIDのみの場合は「コース未登録」と表示します。
- `/dekita-project/?story=7` でID 7の詳細ダイアログを直接開けます。カードから開くとURLが更新され、コピーして共有できます。再読み込み・戻る・進むにも対応します。不明なIDは一覧を表示します。
- 公開済みストーリーの `id` は変更・再利用しないでください。
